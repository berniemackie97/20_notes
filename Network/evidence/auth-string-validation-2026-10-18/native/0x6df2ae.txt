Enforces exactly three things:
  1. buf != NULL
  2. low16(size) == CNetMsg__GetSize(buf)   ; cmp si,ax at 0x6DF2C7
  3. CNetMsg__GetType(buf) != 0
then memcpy(this+4, buf, size) and returns 1.

THERE IS NO MINIMUM SIZE CHECK AND NO UPPER BOUND HERE. The upper bound lives upstream:
CNetMsg__ProcessMsg_Dispatch rejects signed size > 0x400 (0x6DF3D8) and CGameSocket_ReceiveMsg rejects
it earlier still. A subclass Parse adds only its own `type ==` test on top of this.

Consequence for a server: a packet SHORTER than the offsets its handler reads is accepted, and the
handler reads past the copied bytes. That region is zero rather than garbage because
CNetMsg__ResetPacketBuffer (0x6DF290) memsets object+4 for 0x400 bytes, so the missing fields
silently arrive as 0 instead of crashing. Every packet must still span every offset its handler
touches.
